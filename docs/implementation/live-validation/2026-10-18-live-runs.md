## AI (Astra)

The model-call ledger holds 34 calls over the five runs. gpt-6-astra wrote 16 of them (verification questions, executive summaries, recommendations, scenarios) and gpt-5.4 reviewed 18 (the validation pass over Agents 0, 2, 6, 7 and 8).

- 33 calls returned schema-valid output. One review on the base-images run was unavailable; its deterministic result stands and the report says so.
- Tokens: 39,319 in and 7,405 out. Latency: median 4.9 s, 95th percentile 9.6 s.
- Review verdicts on the latest runs: 10 CONCUR and 9 CONCERN, with no DISSENT, so nothing was held for review. A CONCERN is an advisory note on the Analysis tab.

These calls show that the integration works on real, redacted findings. Nobody scored their quality against an answer key.

## Defects found and fixed

| Found on | Defect | Fix |
|---|---|---|
| The workstation import | Every real Nmap XML report starts with `<!DOCTYPE nmaprun>`. The hardened parser refused all DTDs, so real Nmap output always failed with `XML_FORBIDDEN_CONSTRUCT` | `fd4eba9`: allow exactly one bare DOCTYPE with no internal subset and no external identifier; everything else is still refused (ADR-017) |
| example.com | The corporate proxy re-signs TLS, so the probe failed the whole target on certificate verification | `509fa47`: with a configured inspection CA the probe reports `TLS_INSPECTED`, keeps the HTTP controls and leaves the certificate controls NOT_ASSESSED; untrusted chains still fail (ADR-016, decision 9) |
| example.com | The `TLS_INSPECTED` warning of a task that succeeded never reached the report | `035b6ea`: a succeeded task's warnings are listed in the report's limitations |
| First runs | Coverage read "0 of 0 expected" because the driver declared no expected assets. The product reported the empty denominator honestly, and the AI reviewer flagged it | `75c0301`: the driver declares each scenario's expected assets |

## What this does not show

- The M9 plan's targets (`scanme.nmap.org` and an owned Juice Shop) have not been run, and nothing has gone through the harness.
- No public certificate chain was checked over a direct connection.
- Only the Nmap and Trivy importers have seen real output; every other importer is still tested on synthetic fixtures only.
- It all ran on one machine with the dev identity stub and local key files. No IdP, KMS, firewall rules or deployment were involved.

